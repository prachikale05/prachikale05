## 🚀 Featured Projects

### 🏁 ROS2 Differential Drive Robot with Autonomous Navigation
An autonomous ground vehicle engineered to map and navigate virtual environments smoothly.
*   **Problem:** Building a mobile base chassis setup that safely maps and maneuvers through complex spatial layout patterns autonomously without manual tracking instructions.
*   **Solution:** Incorporated sensor configurations (LiDAR, Camera, IMU) using the **SLAM Toolbox** for precise mapping alongside the **Nav2 Stack** and AMCL for active localization path planning.
*   **Technologies:** ROS2 Humble, Gazebo, RViz2, URDF/Xacro, ros2_control, Python.
*   **My Role:** Wrote the model architecture layout using Xacro, wired physical simulator control nodes, and configured Nav2 pipeline limits.

### ⚙️ Robotic Drilling & Pick-and-Place Simulation
A multi-agent production line simulation managing physical manufacturing loops seamlessly.
*   **Problem:** Syncing distinct machine components across a factory floor layout without bumping paths or dropping packages.
*   **Solution:** Implemented topic-driven handoff coordination rules. The primary drilling arm achieved an ultra-precise **0.00806 mm average positioning precision error**.
*   **Technologies:** Ubuntu 22.04, ROS2 Humble, Gazebo Classic, C++, Python, URDF.
*   **My Role:** Configured coordinate frame relationships in Python and created a customized C++ script for robust end-effector tracking commands.

## 👁️ Computer Vision Deep Dive: ANPR System
One of my core engineering focus areas was building an **Automatic Number Plate Recognition (ANPR)** pipeline optimized for Indian vehicle license layout profiles.

### 🔹 Core Capabilities Built
*   **Detection Tier:** Deployed a lightweight **YOLOv8 framework** achieving a **100% detection recall rate** on our 47-plate test baseline.
*   **Text Correction Engine:** Designed custom character correction utilities, upgrading OCR exact-string matches from a baseline **33% up to 80.85% structural accuracy**.
*   **Pipeline Elements:** Implemented double-row text reading modules and multi-variant classification voters to filter sensor anomalies.
*   **Technologies Used:** Python, YOLOv8, OpenCV, PaddleOCR, Pandas, Jupyter Notebooks.
